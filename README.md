# LuxeAura

Professional Salon, Beauty Parlour & Spa Appointment Scheduling System — a React + Vite frontend with luxury styling.

## Features

- Home, Login, Signup, Dashboard, Book Appointment, My Bookings, Notifications, Services, Profile
- Multi-step booking (service, stylist, date/time)
- Search & filter bookings, notifications panel, responsive sidebar
- Local image assets, localStorage persistence for auth & bookings

## Run locally

```bash
npm install
npm run dev
```

Open the URL shown in the terminal (usually `http://localhost:5173`).

## Build for deployment

```bash
npm run build
npm run preview
```

Deploy the `dist` folder to any static host (Netlify, Vercel, GitHub Pages, etc.).

## Demo login

Use any email and password on the login page to access the dashboard.
